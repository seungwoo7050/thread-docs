다음은 하나의 개발 쓰레드에 포함된 커밋 일부다. 학습용 마크다운 문서로 개선해줘.

- 각 커밋의 제목, 순서, 경계를 반드시 유지하고 서로 다른 커밋의 내용을 병합하지 않음
- 각 커밋 내부에서는 git diff를 필요한 코드 스니펫으로 변환하고 불필요한 diff·중복 코드는 제거
- 부족하거나 모호한 설명을 보완하고 설계 의도와 코드 흐름을 명확히 설명
- 코드 스니펫에 학습용 주석 추가
- 영어 표현은 자연스러운 한국어로 바꾸고 AI스러운 문장·단어·표현 제거
- 앞선 커밋과의 관계가 필요한 경우 설명하되 커밋 경계는 유지
- 추가 답변이나 첨언 없이 개선이 완료된 .md 파일로 합니다. 개선된 버전의 파일 이름은 프리/포스트 픽스를 더하지않고 동일하게 유지합니다. 예를 들어 example.md 파일을 제시한 경우 개선된 파일의 이름도 example.md 로 동일하게 유지합니다.
